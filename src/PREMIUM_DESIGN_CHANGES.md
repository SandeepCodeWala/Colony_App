# Premium Design Update

Applied a Jumeirah-inspired luxury hospitality UI language while keeping the original Colony gold/brown color direction.

## Updated areas
- Global `PremiumTheme` palette: ivory, champagne, bronze, glass cards and deep ink typography.
- Font aliases mapped to bundled Poppins fonts for consistent rendering.
- Bottom tabs redesigned with animated active state, glass pill container and premium icon capsules.
- Shared components upgraded: headers, buttons, inputs, dropdowns, cards, tabs, food cards and empty states.
- Explore/Home carousel redesigned with animated hero cards, luxury overlay, premium CTA and pagination.
- Book section redesigned with animated subtabs: Dining, Lounge and All.
- Account section redesigned with tabs: Overview, Menu and Security.
- Loyalty and member screens redesigned with premium loyalty card, shimmer animation and subtabs.
- Reservation, confirmation, payment, date/time and time slot components aligned to the new theme.
- Fixed small issues found during redesign: duplicate `homeNumber` prop, anniversary picker close behavior, missing/bad font aliases, and lounge reservation premature `response` usage.
